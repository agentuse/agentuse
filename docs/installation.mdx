## macOS Desktop

Download the signed DMG from the
[latest GitHub release](https://github.com/agentuse/agentuse/releases/latest),
open it, and move **AgentUse** to Applications. The app includes the AgentUse
runtime and dashboard, so it does not require Node.js or a separate CLI
installation.

On first launch, Desktop setup offers two choices:

- **Launch AgentUse at login** is selected by default and is applied when you
  select **Continue**.
- **Add CLI launcher** optionally creates `~/.local/bin/agentuse` for use in
  Terminal. Setup remains available even if you skip it.

After continuing, the app joins the same guided sample and first-agent flow as
the Web UI.

## Requirements

These requirements apply to command-line installations. The macOS app bundles
its own runtime.

<CardGroup cols={2}>
  <Card title="Node.js" icon="node">
    Node.js 22 or later
  </Card>
  <Card title="Operating system" icon="desktop">
    macOS, Linux, or Windows with WSL
  </Card>
</CardGroup>

Check your Node.js version before installing:

```bash
node --version
```

## Install the CLI globally

A global installation gives you the `agentuse` command in every terminal.

<Tabs>
  <Tab title="npm">
    ```bash
    npm install -g agentuse
    agentuse --version
    ```
  </Tab>
  <Tab title="pnpm">
    ```bash
    pnpm install -g agentuse
    agentuse --version
    ```
  </Tab>
  <Tab title="Bun">
    ```bash
    bun add -g agentuse
    agentuse --version
    ```
  </Tab>
  <Tab title="Yarn">
    ```bash
    yarn global add agentuse
    agentuse --version
    ```
  </Tab>
</Tabs>

## Run without installing

Package runners download AgentUse into their cache and run it without adding a
global command:

<Tabs>
  <Tab title="npx">
    ```bash
    npx agentuse@latest setup
    ```
  </Tab>
  <Tab title="pnpm dlx">
    ```bash
    pnpm dlx agentuse@latest setup
    ```
  </Tab>
  <Tab title="bunx">
    ```bash
    bunx agentuse@latest setup
    ```
  </Tab>
</Tabs>

Use the same runner prefix for later commands. For example:

```bash
npx agentuse@latest serve
```

Install AgentUse globally if you expect to use it regularly.

## Install from source

Use this path when contributing to AgentUse or testing an unreleased build.
It requires Node.js 22+, Bun, and pnpm.

```bash
git clone https://github.com/agentuse/agentuse.git
cd agentuse

corepack enable
pnpm install --frozen-lockfile
pnpm build
npm link

agentuse --version
```

`npm link` points the global `agentuse` command at this checkout. Re-run
`pnpm build` after source changes, or use the repository's development scripts
for watch mode.

## Troubleshooting

<AccordionGroup>
  <Accordion title="agentuse: command not found">
    Confirm that your package manager's global binary directory is on `PATH`:

    ```bash
    npm prefix -g
    pnpm bin -g
    bun pm bin -g
    ```

    Restart your terminal after changing `PATH`. You can also use
    `npx agentuse@latest --version` without changing your global installation.
  </Accordion>

  <Accordion title="Your Node.js version is too old">
    AgentUse requires Node.js 22 or later:

    ```bash
    node --version
    ```

    With [nvm](https://github.com/nvm-sh/nvm), install and select Node.js 22:

    ```bash
    nvm install 22
    nvm use 22
    ```
  </Accordion>

  <Accordion title="Global installation has permission errors">
    Avoid installing with `sudo`. Use a Node.js version manager such as
    [nvm](https://github.com/nvm-sh/nvm) or
    [Volta](https://volta.sh), then retry the global installation.
  </Accordion>

  <Accordion title="The wrong AgentUse version runs">
    Check which executable your shell resolves:

    ```bash
    command -v agentuse
    agentuse --version
    ```

    Remove an older installation made by another package manager, or put the
    intended package manager's global binary directory earlier on `PATH`.
  </Accordion>

  <Accordion title="A browser cannot be opened">
    Use the terminal setup path on a remote, headless, or SSH environment:

    ```bash
    agentuse setup --terminal
    ```
  </Accordion>
</AccordionGroup>
