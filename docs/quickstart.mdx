## Choose how to start

### macOS Desktop

Download AgentUse from the
[latest GitHub release](https://github.com/agentuse/agentuse/releases/latest),
move it to Applications, and open it. On the Desktop setup screen, choose
whether AgentUse should launch at login and optionally add its bundled CLI
launcher for Terminal. Select **Continue** to enter the guided setup.

The app includes the runtime, so macOS Desktop users do not need to install
Node.js or AgentUse globally.

### Command line

```bash
npm install -g agentuse
agentuse --version
```

<Info>
  See [Installation](/installation) for pnpm, Bun, Docker, and development setup options.
</Info>

Set up AgentUse:

```bash
agentuse setup
```

Setup asks four things, and skips any that are already done, so it is safe to
run again:

1. **Where you'll use AgentUse.** From your AI assistant (Claude, ChatGPT, Claude
   Code, Codex, or any app that supports MCP) through
   [AgentUse Cloud](/guides/agentuse-cloud), or only on this computer with no
   account.
2. **Sign in,** for AgentUse Cloud only. Your browser opens; press **Connect**.
3. **The AI that runs your agents.** A key already in your shell comes first,
   then ChatGPT sign-in or pasting an API key. Keys stay on this computer.
4. **Ready.** Setup creates the `my-agents` project and starts AgentUse in the
   background (launchd on macOS, a systemd user service on Linux), so it keeps
   running after you close the terminal and starts again when you log in.

Came from the AgentUse plugin in Claude or ChatGPT? Run the same command. It
shows a code and opens AgentUse Cloud, where you're already signed in: paste
the code and select **Connect**.

### Guided Web setup

Prefer the dashboard? Start the guided Web setup:

```bash
agentuse setup --web
```

AgentUse opens its Web UI and keeps the server running in your terminal.

With no agents yet, Home lists the coding agents on this computer. Select
**Set up** next to Claude Code or Codex: AgentUse adds itself to that app and
adds `automate` and `triage` skills. Then type `/automate` in Claude Code, or
`$automate` in Codex, and say what you want done. If you already have a skill by
one of those names, AgentUse leaves it alone and Home shows what to type instead.
The agent it writes shows up in the
dashboard, where you review and run it. Chat apps such as Claude and ChatGPT
use the AgentUse Cloud address shown on the same page.

<Warning>
  Your coding agent's own login does not authenticate the agents it creates.
  Connect the runtime provider in AgentUse onboarding or Preferences. Do not
  paste API keys, authorization codes, or OAuth callback URLs into coding-agent
  chat.
</Warning>

### Headless setup

On a server or in a script, choose the route and accept the defaults:

```bash
agentuse setup --local --yes
```

Without a browser, the Cloud route prints a link and a code: open the link on
any phone or laptop, sign in, and press **Connect**.

## Create an agent without a coding agent

You do not need Codex, Claude Code, or another coding agent. Complete
`agentuse setup` first, then use the project path shown by setup.

### 1. Configure a runtime provider

```bash
cd ~/.agentuse/projects/my-agents
agentuse provider list
agentuse provider login
```

Choose a provider in the login prompt, then list its current models:

```bash
agentuse models <provider>
```

### 2. Write one agent file

Create `agents/hello.agentuse` and replace `<provider>:<model>` with an exact
model ID from the previous command:

```markdown
---
model: <provider>:<model>
description: Write a friendly greeting
---

Write a short greeting and suggest one useful task you can help with.
```

### 3. Validate and run it

```bash
agentuse doctor agents/hello.agentuse
agentuse run agents/hello.agentuse
```

To inspect the result later:

```bash
agentuse sessions
```

## Start AgentUse again

Setup is only required once. Later, start the registered project and Web UI
with:

```bash
agentuse serve
```
