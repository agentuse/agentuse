## Install AgentUse

```bash
npm install -g agentuse
agentuse --version
```

<Info>
  See [Installation](/installation) for pnpm, Bun, Docker, and development setup options.
</Info>

## Start setup

```bash
agentuse setup
```

Choose **Browser** for the guided setup. AgentUse opens its Web UI and keeps the
server running in your terminal.

<Steps>
  <Step title="Create a project">
    Keep the suggested name, `my-agents`, or change it. AgentUse creates a
    dedicated project under `~/.agentuse/projects/` and shows its full path
    before anything writes an agent file.
  </Step>

  <Step title="Run the sample agent">
    Select **Run sample agent** to see a complete session in the dashboard. The
    sample uses built-in data, needs no provider credentials, and does not
    create an agent file.
  </Step>

  <Step title="Connect a provider">
    In the sample result, select **Create my first agent**, describe the job you
    want to automate, and copy the instructions into your coding agent. It will
    check `agentuse provider list` and guide you through provider login if
    needed. No agent file is written until a runtime provider is ready.
  </Step>

  <Step title="Create your agent">
    Your coding agent creates one focused agent in this project and validates
    it without starting a real run.
  </Step>

  <Step title="Run it">
    Return to the Web UI, open the new agent on the **Agents** page, review it,
    and start its first real run.
  </Step>
</Steps>

<Warning>
  Your coding agent's own login does not authenticate the agents it creates.
  If no AgentUse provider is ready, the onboarding flow will pause and guide
  you through `agentuse provider login` before writing the agent file.
</Warning>

### Terminal or headless setup

If a browser cannot be opened, use the same setup flow in the terminal:

```bash
agentuse setup --terminal
```

AgentUse creates and registers the project, prints its full path, and gives you
the exact next steps. The dashboard is optional for this path.

## Create an agent without a coding agent

You do not need Codex, Claude Code, or another coding agent. Complete
`agentuse setup` first, then use the project path shown by setup.

### 1. Configure a runtime provider

```bash
cd ~/.agentuse/projects/my-agents
agentuse provider list
agentuse provider login
```

Choose a provider in the login prompt, then list its current models:

```bash
agentuse models <provider>
```

### 2. Write one agent file

Create `agents/hello.agentuse` and replace `<provider>:<model>` with an exact
model ID from the previous command:

```markdown
---
model: <provider>:<model>
description: Write a friendly greeting
---

Write a short greeting and suggest one useful task you can help with.
```

### 3. Validate and run it

```bash
agentuse doctor agents/hello.agentuse
agentuse run agents/hello.agentuse
```

To inspect the result later:

```bash
agentuse sessions
```

## Start AgentUse again

Setup is only required once. Later, start the registered project and Web UI
with:

```bash
agentuse serve
```
