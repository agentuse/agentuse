# Coding-agent integrations

Use AgentUse from Codex, Claude Code, or Pi to turn a workflow in your current
conversation into a reusable `.agentuse` file. The integration helps define the
agent, prepare its runtime, and validate it before its first real run.

## Install

Install the repository skill with the cross-host Agent Skills installer:

```bash
npx skills add agentuse/agentuse
```

This is the supported installation path for Codex, Claude Code, Cursor, Gemini
CLI, GitHub Copilot, Goose, OpenCode, Windsurf, and other compatible hosts.
New GitHub Releases do not contain separate coding-assistant packages.

Start a new conversation after installation, then ask your assistant:

```text
Use AgentUse to turn the workflow we just completed into a reusable agent.
```

The installed discovery skill loads the `automate`, `core`, `creator`, and
`tester` guidance from the installed AgentUse CLI. This keeps the authoring
workflow aligned with the CLI version that will validate and run the resulting
agent.

The Pi-specific adapter is currently available to contributors from a source
checkout. Run `bun run integrations:build`, install
`./dist/integrations/pi` with Pi, and start a new session before using
`/automate`.

## Validate and run the resulting agent

The assistant loads current AgentUse guidance from the installed `agentuse`
command. Running and validating the file requires the
[AgentUse CLI](/installation) and a configured model provider.

Review the generated source and setup requirements, then validate and test it:

```bash
agentuse doctor my-agent.agentuse
agentuse test workflow my-agent.agentuse
```

See [testing agents](/guides/testing-agents) for test scope and limitations.
Review the test output before a real run or enabling a schedule.

## Updates and local development

Run `npx skills add agentuse/agentuse` again when you want the latest discovery
skill. Its workflow guidance is version-matched at runtime by the AgentUse CLI.

Contributors can run `bun run integrations:build` in the AgentUse repository.
The generated local-development marketplaces use `agentuse-development`; their
installation commands are in the repository's `integrations` READMEs.
